#  BazarDor (বাজার দর)

### Daily Essential Product Price Tracking Application

BazarDor is a responsive web application that helps users check the latest prices of daily essential products in Bangladesh. Users can explore product categories, compare price changes, view market-wise prices, and track products whose prices have increased or decreased.

The application also includes secure user authentication and profile management.

##  Technologies Used

- Next.js (App Router)
- JavaScript (JSX)
- Tailwind CSS
- BetterAuth
- MongoDB Atlas
- Google & GitHub OAuth
- React Hot Toast
- REST API
- Vercel 

##  Key Features

1. **Profile Management:** Users can view their profile and update their display name.
2. **Product Price Tracking:** Displays today's prices, previous prices, and percentage changes.
3. **Price Increase & Decrease:** Separate sections showing the top six products with increasing and decreasing prices.
4. **Product Details:** Protected product detail pages with minimum, maximum, average, and market-wise prices.
5. **User Authentication:** Email/password registration and login, including Google and GitHub social login using BetterAuth.
